Build from source

You need macOS and Bun 1.4.

$ git clone https://github.com/milolabs/matters-app
$ cd matters-app
$ bun install
$ bun run dev:desktop:demo   # a made-up mailbox, no account needed
$ bun run dev:desktop        # your own accounts
